# Bedrock — Dawn native prototype

One SwiftUI Xcode project for iOS 17+ and macOS 14+. Working name and bundle display name are configurable in Xcode build settings. Open `Bedrock.xcodeproj`; select Bedrock and a Mac or iPhone Simulator destination. No development team is embedded. Simulator builds require no team. For a physical phone, the owner must configure usable development signing in Xcode and select an authorized team in Signing & Capabilities, and use an already authorized device. This task did not create credentials, enable Developer Mode, or distribute a release.

The app follows Four Immeasurables → Heart Sutra → **42** → quiet rest. Only those three steps gate Dawn completion. Ten foundation slots exist; slots 4–10 are unassigned. Mel clarified that 42 means a 42-minute meditation session. The short title stays “42,” with that explanation visible and used in completion accessibility labels. There is no timer or inferred guided practice.

Four Immeasurables verses are copied exactly from this repository's `js/app.js` LITURGY, whose README identifies the owner-approved Daily Prayers text. Mel clarified that Four Immeasurables is his practice and Heart Sutra is him reading the Heart Sutra. The cards say “Your Four Immeasurables practice” and “Read the Heart Sutra”; no reading text or guided instruction is invented. The 42 card identifies the owner-specified 42-minute meditation session. Original web practice and audio remain unchanged.

Hold for 1.6 seconds, then release to complete. Early release, moving more than 30 points, leaving the active app, or crossing a daily boundary cancels. The control says “Hold to seal” and uses a solid fill, with no slider thumb. A discreet Completion options menu offers “Seal without holding”; that action and VoiceOver activation open a confirmation, with Return keyboard support on Mac. The visible options label preserves discoverability for people who cannot hold. The generic nudge sentence and all prototype disclaimers are absent from cards. Undo last is always available after completion (Command-Z on Mac). Reset requires confirmation, including from the resting screen. All motion is static except the functional progress indicator; completion needs no animation. Text scrolls to accommodate small screens and large type.

Progress is Codable JSON in the app's local Application Support/Bedrock/dawn.json, written atomically. A local-calendar date key is reconciled on launch, active-scene changes, and a foreground timer. A new day clears today's completion and suggests one quiet breath for previously missed items. Suggestions neither rewrite liturgy nor count as completion. Confirmation is tied to its original day and item. Disk failures are displayed. No cloud, notifications permission, feed restrictions, photos, planner, analytics, or subscriptions.
